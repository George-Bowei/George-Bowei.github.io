# George (Bowei) Zheng — Personal Website

Static academic portfolio for GitHub Pages. The site is in `index.html` and its styles are in `assets/site.css`.

## Publish on GitHub Pages

1. Create a **public** repository named `George-Bowei.github.io` under the GitHub account `George-Bowei`.
2. Add these files to the repository's `main` branch.
3. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
4. The included workflow deploys the site after each push to `main`. The site address will be `https://george-bowei.github.io/`.

With a public repository and no other collaborators, visitors can read the website while only the repository owner can change its source. Keep the repository's write access limited to your account.

## Update the site

Edit the relevant section in `index.html`, then push the change to `main`. The Pages workflow will publish it automatically.
